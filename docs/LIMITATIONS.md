# Limitations and Future Scope

GraphGuard is an educational prototype. Lexical indicators are not a complete prompt-injection defense and can miss novel attacks or flag benign language. The simulated agent and tools do not represent provider-specific behavior, authentication, distributed tracing, adversarial adaptation or real-world latency.

Future work includes signed provenance for retrieval, semantic and model-based classifiers, capability tokens, sandboxed tool execution, rate limits, policy versioning, reviewer identity integration, and red-team evaluation against diverse agents.
